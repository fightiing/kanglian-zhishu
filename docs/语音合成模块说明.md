# 语音合成(TTS)模块开发文档

## 一、模块概述

### 1.1 功能定位
语音合成(TTS)模块是**全系统公共能力**,无业务限制,为所有页面/场景提供语音播报功能,特别适配老年用户的听力特点。

### 1.2 核心特性
- ✅ **全局可调用**：任何模块均可调用,无依赖限制
- ✅ **老年适配参数**：语速4、音量7、女声(0)默认锁定
- ✅ **文本自动简化**：剔除专业术语,替换为通俗表达
- ✅ **单例模式**：全局共享TTS实例,节省资源

### 1.3 应用场景
- 药品识别结果播报
- 语音询问答复播报
- 医生推荐结果播报
- 首页疾病信息播报

```python
from aip import AipSpeech
import base64
import sys
import os
sys.path.append(os.path.join(os.path.dirname(__file__), '..'))
from config.baidu_config import BAIDU_TTS_CONFIG

class BaiduTTS:
    """百度语音合成封装类"""
    
    def __init__(self, app_id, api_key, secret_key):
        """初始化百度TTS客户端"""
        self.client = AipSpeech(app_id, api_key, secret_key)
        
        # 老年适配默认参数(锁定)
        self.default_params = {
            'spd': 4,   # 语速(0-15), 4为适中偏慢
            'vol': 7,   # 音量(0-15), 7为较大音量
            'per': 0    # 发音人(0女声, 1男声, 3情感男声, 4情感女声)
        }
```

**老年适配参数说明**：

| 参数 | 值 | 说明 | 为什么这样设置 |
|------|---|------|----------------|
| spd | 4 | 语速 | 老年人听力反应慢,4适中偏慢 |
| vol | 7 | 音量 | 老年人听力下降,7较大音量 |
| per | 0 | 女声 | 女声更柔和,老年人接受度高 |

#### (2) 语音合成核心方法
```python
def synthesize(self, text, spd=None, vol=None, per=None):
    """
    语音合成 - 全局通用接口
    
    Args:
        text: 待播报文字(自动简化处理)
        spd: 语速(可选,默认4)
        vol: 音量(可选,默认7)
        per: 发音人(可选,默认0女声)
    
    Returns:
        Base64编码的MP3音频数据
    """
    # 使用默认参数(如未指定)
    params = {
        'spd': spd if spd is not None else self.default_params['spd'],
        'vol': vol if vol is not None else self.default_params['vol'],
        'per': per if per is not None else self.default_params['per']
    }
    
    # 简化文本(适配老人理解)
    simplified_text = self._simplify_text(text)
    
    # 调用百度TTS
    result = self.client.synthesis(
        simplified_text,
        'zh',
        1,
        params
    )
    
    # 判断是否成功
    if not isinstance(result, dict):
        # 成功返回音频二进制数据
        audio_base64 = base64.b64encode(result).decode('utf-8')
        return audio_base64
    else:
        # 失败返回错误信息
        raise Exception(f"TTS合成失败: {result}")
```

#### (3) 文本自动简化
```python
def _simplify_text(self, text):
    """
    简化播报文字(适配老人理解能力)
    1. 剔除专业术语
    2. 控制单句长度≤80字
    3. 替换复杂表述
    """
    # 专业术语替换表
    replacements = {
        '口服': '吃',
        '用法用量': '怎么吃',
        '不良反应': '副作用',
        '禁忌': '不能吃的情况',
        'bid': '每天两次',
        'tid': '每天三次',
        'qd': '每天一次',
        'qn': '睡前',
        'pc': '饭后',
        'ac': '饭前'
    }
    
    simplified = text
    for old, new in replacements.items():
        simplified = simplified.replace(old, new)
    
    # 控制长度(如果超过80字,截取前80字)
    if len(simplified) > 80:
        simplified = simplified[:80] + '...'
    
    return simplified
```

**文本简化示例**：

| 原始文本 | 简化后文本 |
|---------|-----------|
| 口服,一日三次,饭后服用 | 吃,每天三次,饭后服用 |
| 用法用量:tid | 怎么吃:每天三次 |
| 禁忌症:肝肾功能不全者禁用 | 不能吃的情况:肝肾功能不全者禁用 |

```python
# 全局TTS实例(单例模式)
_tts_instance = None

def get_tts_instance():
    """获取全局TTS实例"""
    global _tts_instance
    if _tts_instance is None:
        # 从配置文件读取API密钥
        _tts_instance = BaiduTTS(
            app_id=BAIDU_TTS_CONFIG['APP_ID'],
            api_key=BAIDU_TTS_CONFIG['API_KEY'],
            secret_key=BAIDU_TTS_CONFIG['SECRET_KEY']
        )
    return _tts_instance

def speak(text, **kwargs):
    """
    快捷语音播报函数 - 全局可调用
    
    使用示例:
        from common.baidu_tts import speak
        speak("布洛芬缓释胶囊, 一次1粒, 每天2次")
    
    Args:
        text: 待播报文字
        **kwargs: 可选参数(spd, vol, per)
    
    Returns:
        Base64编码的音频数据
    """
    tts = get_tts_instance()
    return tts.synthesize(text, **kwargs)
```

### 2.3 Flask后端接口 ✅

**文件位置**：`web_app/app.py`

```python
from common.baidu_tts import speak

@app.route('/api/common/tts', methods=['POST'])
def common_tts():
    """
    通用语音合成接口 - 全局可调用
    请求体: {"text": "待播报文字", "spd": 4, "vol": 7, "per": 0}
    返回: {"success": true, "audio": "base64音频数据"}
    """
    data = request.get_json()
    text = data.get('text', '').strip()
    
    if not text:
        return jsonify({
            'success': False,
            'message': '播报文字不能为空'
        }), 400
    
    try:
        # 可选参数
        spd = data.get('spd')  # 语速
        vol = data.get('vol')  # 音量
        per = data.get('per')  # 发音人
        
        # 调用通用TTS
        audio_base64 = speak(text, spd=spd, vol=vol, per=per)
        
        return jsonify({
            'success': True,
            'audio': audio_base64
        })
    except Exception as e:
        return jsonify({
            'success': False,
            'message': f'语音合成失败: {str(e)}'
        }), 500
```

```javascript
async function callTTS(text) {
    try {
        const response = await fetch('/api/common/tts', {
            method: 'POST',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ text: text })

        }

        console.error('TTS调用失败:', error);

    }
}
```

## 六、性能优化建议

### 6.1 缓存音频

对于固定文本（如"请稍候"、"识别成功"），可缓存音频：

```python
# common/tts_cache.py
import hashlib

_audio_cache = {}

def speak_with_cache(text, **kwargs):
    """带缓存的TTS"""
    cache_key = hashlib.md5(text.encode()).hexdigest()
    
    if cache_key in _audio_cache:
        return _audio_cache[cache_key]
    
    audio = speak(text, **kwargs)
    _audio_cache[cache_key] = audio
    return audio
```

### 6.2 异步处理

避免TTS调用阻塞主线程：

```python
# Flask异步处理
from concurrent.futures import ThreadPoolExecutor
executor = ThreadPoolExecutor(max_workers=5)

@app.route('/api/common/tts', methods=['POST'])
def common_tts():
    data = request.get_json()
    text = data.get('text')
    
    # 异步合成
    future = executor.submit(speak, text)
    audio = future.result(timeout=10)
    
    return jsonify({'success': True, 'audio': audio})
```
